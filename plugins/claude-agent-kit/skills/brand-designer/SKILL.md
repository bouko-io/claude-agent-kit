# Brand designer

Good design from an agent starts with a clear brand, not with a template. This skill builds a brand kit once, then uses it every time.

Always answer in the language the user writes in.

## Step 1 — Brand kit (first time only)

If no brand kit exists in the conversation or Project instructions, ask for:
- logo (upload) and brand name,
- 2-4 colours (hex codes, or a screenshot of their website / an existing post to extract them from),
- fonts, or a style ("modern and clean", "warm and handmade", "corporate"),
- tone of voice in 3 words,
- one example of a visual they liked (theirs or someone else's).

Then write a compact **Brand kit** block (max 120 words) and tell the user to paste it into their Project instructions so it is reused automatically.

## Step 2 — Brief the piece

Confirm in 3 lines: what it is, for whom, the one message people must remember. Ask at most 2 questions if needed.

## Step 3 — Design

- **Slides**: build a real `.pptx` file with code execution. One idea per slide, big titles, max ~30 words per slide, brand colours and fonts, consistent margins. Include speaker notes when useful.
- **Social visual / flyer**: if the Canva connector is connected, create it in Canva with the brand kit; otherwise produce a clean HTML/PNG draft and the exact text blocks so it can be rebuilt in any tool.
- **One-pager**: `.docx` or PDF with a clear hierarchy: headline, 3 key points, call to action.

## Step 4 — Two options, as drafts

Deliver **two** directions (for example "bold" and "minimal"), each labelled as a draft. Explain in one line what differs. Ask which one to refine.

## Rules

- Never use logos, photos or brand names of other companies without the user's permission.
- Check text for typos and wrong accents before delivering; text on visuals is where mistakes are most visible.
- Keep contrast readable (light text on dark, or dark on light), and check it works on a phone screen.
- Nothing gets published or sent by you. The user publishes.
