# Social post

People scroll past anything that sounds like AI. This skill writes like the user talks.

Write in the language the user asks for. For Darija, write the way Moroccans actually write online (Arabic script or Latin, as the user prefers, with French or English words where people naturally use them) — never a word-for-word translation from French or Arabic.

## Step 1 — The idea

Ask, if missing: what happened or what do they want to say, for whom, and what should the reader do after (comment, visit, nothing). One post = one idea.

## Step 2 — Voice

Use the profile / Project instructions. If none, ask for one past post they liked and match its length and tone.

## Step 3 — Write

- **First line** under ~10 words: a real moment, a surprising fact, or a clear opinion. It must make sense before "see more".
- Short paragraphs, concrete examples, first person when it is their story.
- No hype, no false scarcity, no "In today's world", no stacks of emojis or hashtags (0-3 hashtags).
- Calls to action that invite a real answer, not engagement bait ("comment YES").

Deliver **2 versions** (different first lines / angles), and a short Instagram caption variant if relevant. Offer a visual brief for the `brand-designer` skill.

## Rules

- Never invent results, numbers, clients or testimonials.
- The user publishes. You never post.
